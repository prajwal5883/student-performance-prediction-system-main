# 🎓 Student Performance Prediction System

## 📌 Project Overview
The **Student Performance Prediction System** is a Machine Learning project designed to analyze and predict student academic performance based on different educational factors. The system helps identify students who are at risk and supports teachers in taking corrective academic actions.

---

## 🚀 Features
- Predicts student **Pass/Fail** results
- Identifies **at-risk students**
- Provides **data-driven academic insights**
- Helps teachers improve student performance
- Visualizes student performance using graphs

---

## 📊 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📁 Dataset Files
- `student_academic_data.csv`
- `at_risk_students.csv`

---

## 🧠 Machine Learning Models Used
- Logistic Regression
- Decision Tree
- Naive Bayes
- Support Vector Machine (SVM)

---

## 📌 Project Output
- Student result prediction
- Performance visualization graphs
- At-risk student identification list
